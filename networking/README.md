# Networking Examples

This folder currently contains a tiny starter program that demonstrates the basic structure of a C++ networking example.

## Files

- test.cpp - a minimal hello-world style example used as a starting point.

## Build and Run

Compile it with:

```bash
g++ test.cpp -o test
```

Run it:

```bash
./test
```

## Notes

This folder is intended to be expanded with real networking examples such as sockets, HTTP clients, or server code in future updates.
